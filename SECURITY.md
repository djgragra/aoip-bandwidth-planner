# Security policy

## Supported versions

Only the latest version, the one published on https://onairgarage.com/tools/aoip-bandwidth-planner/, is supported.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Write to **hello@onairgarage.com** with the page address, your browser and the steps to reproduce it. You will get an answer, and a fix is published in the next version.

Never send passwords, tokens or API keys: they are not needed to describe a problem.

## What the app does

It is a static web page that runs in your browser. The README says what it stores and which addresses it contacts, if any.
